# ROWBREAK — 置いて消す 8×8 ブロック

ブロックパズル ROWBREAK。8×8 の盤に、下に出る 3 つのブロックを好きな順に置き、縦か横の列をうめて消していく。今日の盤は全員に同じ順番でブロックが配られるので、同じ条件でスコアを比べられる。

## 🔗 リンク

- 遊ぶ: https://rowbreak.t-of.workers.dev/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

- 下の 3 つのブロックを、指（PC はマウス）で盤へ運んで置く。回せない。好きな順でよい。
- 縦か横の 1 列がうまると、その列が消えて点になる。行と列は同時に数えて全部消す。
- 3 つとも置くと次の 3 つ。どれも置けなくなったら終わり。
- 点: 置いた 1 マス 1 点。消した列 n 本で 10 × n²。続けて消すと 2 回目から +20 × (連続 − 1)。盤が空になったら +300。
- **今日の盤**: 日付から決まる同じ順番のブロックが全員に配られる。記録は 1 日 1 回。途中で閉じても続きから。
- **エンドレス**: 何度でも。途中で閉じても続きから。
- 画面の文字は日本語と英語（端末の言葉に合わせる。上の帯で切り替えられる）。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node tools/test.mjs           # 決まりの自己チェック（形の引き方・置く・消す・点・終わり・今日の盤・保存）
```

- `logic.js`: 決まり（DOM に触らない）。`main.js`: 画面・操作・音・保存。
- 保存: `rowbreak.settings`（音・言葉・説明を見たか・モード）、`rowbreak.stats`（エンドレスの記録）、`rowbreak.endless`（途中の遊び）、`rowbreak.daily`（今日の盤の日ごとの記録と途中）。
- 形の番号（`logic.js` の `DEFS` の並び）は保存と今日の盤が使うので、並べ替えない。足すなら最後に。
